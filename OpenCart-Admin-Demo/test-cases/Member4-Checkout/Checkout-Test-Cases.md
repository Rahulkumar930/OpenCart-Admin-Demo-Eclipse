# Member 4 - Checkout Test Cases

## TC_CHECKOUT_001 - Open Checkout

**Objective:** Verify that checkout page opens.

**Steps:**
1. Add a product to cart.
2. Open cart.
3. Click Checkout.

**Expected Result:**
Checkout page should open.

---

## TC_CHECKOUT_002 - Enter Address

**Objective:** Verify customer address entry.

**Steps:**
1. Open checkout.
2. Enter customer details.
3. Enter address.
4. Enter city and postcode.
5. Select country and region.

**Expected Result:**
Address information should be accepted.

---

## TC_CHECKOUT_003 - Place Order

**Objective:** Verify order placement.

**Steps:**
1. Add a product to cart.
2. Go to checkout.
3. Enter required information.
4. Select payment method.
5. Confirm order.

**Expected Result:**
Order should be placed successfully.
