# OpenCart Admin Demo

## Project
OpenCart Admin Demo

## Website
https://www.opencart.com/

## Technology
- Java
- Selenium WebDriver
- Maven
- JUnit 5
- Eclipse

## How to import into Eclipse
1. Open Eclipse.
2. File -> Import.
3. Maven -> Existing Maven Projects.
4. Select this project folder.
5. Click Finish.
6. Right-click the project -> Maven -> Update Project.

## Run
Right-click `OpenCartAdminDemoTest.java` -> Run As -> JUnit Test.

## GitHub
After importing the project into Eclipse, use Team -> Share Project to initialize Git,
then commit and push the project to your GitHub repository.
